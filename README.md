# What’s new in Chrome

All Chrome release notes sources combined into one feed:

- Release notes on [Chrome for Developers](https://developer.chrome.com/release-notes)
- What’s new in Chrome in [Chrome for Developers Blog](https://developer.chrome.com/blog)
- Release notes on [Chrome Status](https://chromestatus.com/)

A GitHub Action rebuilds the feed daily and publishes it to GitHub Pages:

[pepelsbey.github.io/whats-new-in-chrome/feed.xml](https://pepelsbey.github.io/whats-new-in-chrome/feed.xml)

Why? Because the official [Chrome for Developers Blog’s feed](https://developer.chrome.com/static/blog/feed.xml) often goes stale for months and doesn’t include Chrome releases anymore.
